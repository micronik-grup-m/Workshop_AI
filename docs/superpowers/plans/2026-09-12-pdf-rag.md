# RAG peste PDF-uri Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **No git repository in this project.** Do not use worktrees, commits, or
> diff-based review packages. Verify each task by actually running
> `mvn test` / `mvn spring-boot:run` / `docker compose up` and reading the
> real output. Task review packages are full-file listings (which files
> changed and their complete current content), not git diffs.

**Goal:** Add a PDF-based RAG (Retrieval-Augmented Generation) subsystem
to the Workshop_AI backend — upload a PDF, index it semantically in
Postgres/pgvector, and let the AI model in LM Studio search it through
new MCP tools, mirroring how `EmployeeMcpTools` already works.

**Architecture:** REST upload (`DocumentController`, JWT/ADMIN) →
`DocumentIngestionService` (PDF → pages → chunks → embeddings → pgvector)
→ `DocumentMcpTools` (MCP, unauthenticated) → `DocumentQueryService`
(similarity search) → plain-text results, exactly like `EmployeeMcpTools`.
No second LLM call happens in the backend — the model in LM Studio
synthesizes the final answer from the returned fragments.

**Tech Stack:** Spring AI 2.0.1 (`spring-ai-pdf-document-reader`,
`spring-ai-starter-model-openai`, `spring-ai-starter-vector-store-pgvector`),
PostgreSQL + pgvector (`pgvector/pgvector:pg16`), Flyway, Lombok
(`@Slf4j`), Testcontainers (`org.testcontainers:postgresql`,
`org.testcontainers:junit-jupiter`).

**Spec:** `docs/superpowers/specs/2026-09-12-pdf-rag-design.md`

## Global Constraints

- Feature works **only** under the `docker` Spring profile (Postgres +
  pgvector). The default H2 profile keeps booting and running the
  existing Employee/Auth suite unchanged; RAG endpoints/tools may fail at
  call-time on H2 (documented limitation), but adding the new
  dependencies/config **must not break existing tests or existing local
  boot** — this is verified explicitly in Task 1 before any RAG code
  exists.
- New Maven dependencies (no explicit `<version>`, BOM-managed —
  verified to exist at `2.0.1` on Maven Central):
  `org.springframework.ai:spring-ai-pdf-document-reader`,
  `org.springframework.ai:spring-ai-starter-model-openai`,
  `org.springframework.ai:spring-ai-starter-vector-store-pgvector`.
  Plus `org.projectlombok:lombok` (`optional`, version managed by
  `spring-boot-starter-parent`) and, test-scope,
  `org.testcontainers:postgresql` + `org.testcontainers:junit-jupiter`
  (versions managed by `spring-boot-starter-parent`).
- Docker image for the `db` service becomes `pgvector/pgvector:pg16`
  (confirmed to exist on Docker Hub) — drop-in replacement for
  `postgres:16-alpine`, same env vars/volume.
- Embedding model: **`nomic-embed-text-v1.5`**, loaded in LM Studio in
  **embedding mode** — produces 768-dimension vectors. The Postgres
  `vector_store.embedding` column and `spring.ai.vectorstore.pgvector.dimensions`
  are both fixed at `768` to match.
- Verified Spring AI 2.0.1 API surface (used verbatim below — do not
  substitute alternate method names):
  - `org.springframework.ai.reader.pdf.PagePdfDocumentReader` —
    constructor `PagePdfDocumentReader(Resource)`, method `read(): List<Document>`,
    metadata key constants `METADATA_START_PAGE_NUMBER`, `METADATA_FILE_NAME`.
  - `org.springframework.ai.transformer.splitter.TokenTextSplitter` —
    `TokenTextSplitter.builder().build()`, method `split(List<Document>): List<Document>`.
    Splitting **preserves and copies all metadata** (including page
    number) from the parent Document onto every chunk — verified against
    the official ETL pipeline reference.
  - `org.springframework.ai.document.Document` — immutable; add metadata
    via `document.mutate().metadata(key, value).build()`, never by
    mutating `getMetadata()` directly.
  - `org.springframework.ai.vectorstore.VectorStore` — `add(List<Document>)`,
    `delete(String filterExpression)` (e.g. `"documentId == '3'"`),
    `similaritySearch(SearchRequest)`.
  - `org.springframework.ai.vectorstore.SearchRequest` —
    `SearchRequest.builder().query(String).topK(int).build()`.
  - `org.springframework.ai.embedding.EmbeddingModel` — one abstract
    method to implement for a fake/test double: `call(EmbeddingRequest): EmbeddingResponse`,
    plus `embed(Document): float[]`. `EmbeddingRequest(List<String> inputs, EmbeddingOptions options)`,
    `.getInstructions(): List<String>`. `Embedding(float[] embedding, Integer index)`.
    `EmbeddingResponse(List<Embedding>)`.
- `spring.ai.openai.embedding.*` properties (verified against the
  official reference): `base-url`, `api-key`, `model` (flat property —
  unlike the OpenAI *chat* properties, which nest under `options`, the
  embedding properties do not), `dimensions`.
- Existing project conventions to follow exactly: package-per-feature
  under `ro.micronikgrupm.mcp.client.<feature>`, plain Java beans with
  manual getters/setters for JPA entities (see `Employee.java`), records
  for REST DTOs (see `EmployeeResponse.java`), `GenerationType.IDENTITY`
  for all `@Id` fields (already used by `Employee`/`AppUser` — avoids the
  AUTO/Postgres-sequence pitfall this project hit before with Envers),
  `GlobalExceptionHandler` in `ro.micronikgrupm.mcp.client.common` for
  all `@ExceptionHandler`s, `SecurityConfig` in
  `ro.micronikgrupm.mcp.client.security` for all route rules, MCP tools
  return plain formatted text (never JSON), matching `EmployeeMcpTools`.
- New Lombok usage is scoped to the new RAG package only (`@Slf4j` on
  `DocumentIngestionService`, `DocumentQueryService`, `DocumentController`,
  `DocumentMcpTools`) — do not retrofit `@Slf4j` onto existing Employee/
  security classes; that is out of scope for this plan.

- [ ] **Step 1: Write the failing tests**

`src/test/java/ro/micronikgrupm/mcp/client/rag/FakeEmbeddingModelTestConfig.java`
— a keyword-bucket fake embedding model. It does not call any real
embedding service (LM Studio is not required to run these tests): each
of a small fixed set of keywords maps to one vector dimension, set to
`1.0` if the text (lower-cased) contains that keyword, `0.0` otherwise.
This makes similarity search deterministic and testable without a real
model, while still exercising the full ingestion → storage → retrieval
pipeline for real against Postgres:

```java
package ro.micronikgrupm.mcp.client.rag;

import org.springframework.ai.document.Document;
import org.springframework.ai.embedding.Embedding;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.ai.embedding.EmbeddingRequest;
import org.springframework.ai.embedding.EmbeddingResponse;
import org.springframework.boot.test.context.TestConfiguration;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Primary;

import java.util.ArrayList;
import java.util.List;

@TestConfiguration
public class FakeEmbeddingModelTestConfig {

    private static final List<String> KEYWORDS = List.of("alpha", "beta", "gamma", "delta");
    public static final int DIMENSIONS = 768;

    @Bean
    @Primary
    public EmbeddingModel fakeEmbeddingModel() {
        return new EmbeddingModel() {

            @Override
            public EmbeddingResponse call(EmbeddingRequest request) {
                List<Embedding> embeddings = new ArrayList<>();
                List<String> inputs = request.getInstructions();
                for (int i = 0; i < inputs.size(); i++) {
                    embeddings.add(new Embedding(vectorFor(inputs.get(i)), i));
                }
                return new EmbeddingResponse(embeddings);
            }

            @Override
            public float[] embed(Document document) {
                return vectorFor(document.getText());
            }

            private float[] vectorFor(String text) {
                float[] vector = new float[DIMENSIONS];
                String normalized = text == null ? "" : text.toLowerCase();
                for (int i = 0; i < KEYWORDS.size(); i++) {
                    vector[i] = normalized.contains(KEYWORDS.get(i)) ? 1f : 0f;
                }
                return vector;
            }
        };
    }
}
```

```java
package ro.micronikgrupm.mcp.client.rag;

import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.document.Document;
import org.springframework.ai.reader.pdf.PagePdfDocumentReader;
import org.springframework.ai.transformer.splitter.TokenTextSplitter;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.core.io.ByteArrayResource;
import org.springframework.stereotype.Service;
import org.springframework.web.multipart.MultipartFile;

import java.io.IOException;
import java.time.Instant;
import java.util.List;

@Slf4j
@Service
public class DocumentIngestionService {

    private final RagDocumentRepository repository;
    private final VectorStore vectorStore;

    public DocumentIngestionService(RagDocumentRepository repository, VectorStore vectorStore) {
        this.repository = repository;
        this.vectorStore = vectorStore;
    }

    public RagDocument ingest(MultipartFile file) {
        String filename = file.getOriginalFilename();
        if (filename == null || !filename.toLowerCase().endsWith(".pdf")) {
            throw new IllegalArgumentException("Doar fișiere PDF sunt acceptate: " + filename);
        }

        byte[] content;
        try {
            content = file.getBytes();
        } catch (IOException e) {
            throw new IllegalArgumentException("Nu am putut citi fișierul încărcat: " + filename, e);
        }

        PagePdfDocumentReader reader = new PagePdfDocumentReader(new ByteArrayResource(content));
        List<Document> pages = reader.read();

        TokenTextSplitter splitter = TokenTextSplitter.builder().build();
        List<Document> chunks = splitter.split(pages);

        RagDocument ragDocument = new RagDocument();
        ragDocument.setFilename(filename);
        ragDocument.setUploadedAt(Instant.now());
        ragDocument.setPageCount(pages.size());
        ragDocument.setChunkCount(chunks.size());
        ragDocument = repository.save(ragDocument);

        String documentId = String.valueOf(ragDocument.getId());
        List<Document> taggedChunks = chunks.stream()
                .map(chunk -> chunk.mutate()
                        .metadata("documentId", documentId)
                        .metadata("filename", filename)
                        .build())
                .toList();

        vectorStore.add(taggedChunks);
        log.info("Indexat documentul '{}' (id={}): {} pagini, {} fragmente",
                filename, ragDocument.getId(), pages.size(), chunks.size());

        return ragDocument;
    }

    public void delete(Long documentId) {
        RagDocument ragDocument = repository.findById(documentId)
                .orElseThrow(() -> new DocumentNotFoundException(documentId));
        vectorStore.delete("documentId == '" + documentId + "'");
        repository.delete(ragDocument);
        log.info("Șters documentul '{}' (id={})", ragDocument.getFilename(), documentId);
    }
}
```

```java
package ro.micronikgrupm.mcp.client.rag;

import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.document.Document;
import org.springframework.ai.reader.pdf.PagePdfDocumentReader;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;

import java.util.List;

@Slf4j
@Service
public class DocumentQueryService {

    private final VectorStore vectorStore;
    private final RagDocumentRepository repository;

    public DocumentQueryService(VectorStore vectorStore, RagDocumentRepository repository) {
        this.vectorStore = vectorStore;
        this.repository = repository;
    }

    public String search(String query, int topK) {
        List<Document> results = vectorStore.similaritySearch(
                SearchRequest.builder().query(query).topK(topK).build());
        log.debug("Căutare '{}' -> {} rezultate", query, results.size());
        if (results.isEmpty()) {
            return "Niciun fragment relevant găsit.";
        }
        return results.stream()
                .map(this::describe)
                .reduce((a, b) -> a + "\n" + b)
                .orElse("");
    }

    public String listAll() {
        List<RagDocument> documents = repository.findAll();
        if (documents.isEmpty()) {
            return "Niciun document încărcat.";
        }
        return documents.stream()
                .map(d -> "id=%d, %s, %d pagini, %d fragmente".formatted(
                        d.getId(), d.getFilename(), d.getPageCount(), d.getChunkCount()))
                .reduce((a, b) -> a + "\n" + b)
                .orElse("");
    }

    private String describe(Document document) {
        Object filename = document.getMetadata().get("filename");
        Object page = document.getMetadata().get(PagePdfDocumentReader.METADATA_START_PAGE_NUMBER);
        return "[%s, pagina %s] %s".formatted(filename, page, document.getText());
    }
}
```

    @McpTool(name = "searchDocuments", description = "Caută fragmente relevante în documentele PDF încărcate, pe baza unei întrebări")
    public String searchDocuments(
            @McpToolParam(description = "Întrebarea sau textul căutat", required = true) String query,
            @McpToolParam(description = "Numărul maxim de fragmente întoarse (opțional, implicit 5)", required = false) Integer topK) {
        int effectiveTopK = topK != null ? topK : 5;
        log.info("MCP searchDocuments: query='{}', topK={}", query, effectiveTopK);
        return queryService.search(query, effectiveTopK);
    }

    @McpTool(name = "listDocuments", description = "Listează documentele PDF încărcate")
    public String listDocuments() {
        return queryService.listAll();
    }
}
